# ViralEngine Fold Companion (Honor Magic V2)

Нативный Android-хелпер для принудительного включения внешнего экрана (Display 1) на раскладных смартфонах Honor Magic V2 в 100% плоском раскрытом состоянии (180°).

## Возможности
1. **Виджет в Шторке Уведомлений (Quick Settings Tile):** Позволяет в 1 клик прямо из шторки Honor MagicOS включить или выключить телесуфлёр на внешнем экране.
2. **Принудительная подача сигнала (Display 1):** Использует `android.app.Presentation` и `FLAG_KEEP_SCREEN_ON` для обхода аппаратной блокировки касаний Honor MagicOS на 180°.
3. **Полноэкранный WebGL/HTML5 Телесуфлёр:** Отображает суфлёр ViralEngine без рамок и тайм-аутов гашения экрана.

## Сборка APK

### Вариант 1: Через Android Studio
1. Откройте папку `android-companion` в Android Studio.
2. Нажмите **Build ➔ Build APK(s)**.
3. Установите созданный APK-файл `app-debug.apk` на ваш Honor Magic V2.

### Вариант 2: Через командную строку (Gradle)
```bash
cd android-companion
./gradlew assembleDebug
```
Скомпилированный APK будет находиться по адресу: `android-companion/app/build/outputs/apk/debug/app-debug.apk`.

## Использование на Honor Magic V2
1. Откройте приложение `ViralEngine Companion` на телефоне и введите ссылку на вашу студию/проект.
2. Смахните **Шторку управления Honor MagicOS**, нажмите значок **Редактировать значки (Карандаш)**.
3. Добавьте плитку **Суфлёр 180°** в активные значки.
4. Нажмите на плитку **Суфлёр 180°** — внешний экран мгновенно загорится и запустит суфлёр даже при 100% разложенном телефоне!
